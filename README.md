# Car Photo Shot List

An installable web app for selling a used car: a shot list matched to your vehicle, a guide camera with a framing outline, a damage map, quick photo checks, licence plate blur, posting order for each listing site, and an ad writer.

Everything stays on the phone. Nothing is uploaded.

## Install

Open the site in Chrome on Android and tap **Install app** (or Chrome menu, then **Install app** / **Add to Home screen**).

## Files

- `index.html`: the whole app
- `manifest.webmanifest`, `icon-*.png`: install details and icons
- `sw.js`: offline support
